title: "Install on VS Code"
description: "Detect, learn and fix issues directly in VS Code and its forks"
---

<Steps>
  <Step title="Download the extension">
    Download the VSIX from the Symbiotic portal or use the link provided by your administrator.
  </Step>
  <Step title="Install the extension">
    In the interface, go to `Extensions > … More actions > Install from VSIX…`
    Or you use the command `Extensions: Install from VSIX…`

    Select the file and click on `Install`
  </Step>
  <Step title="Log in">
    Once the installation is finished a notification will ask you to log-in using your Symbiotic Security account.

    <Steps>
      <Step title="Click on Log In" icon="square-arrow-out-up-right">
        ![Extension Log In Notification Pn](/flow/devs/images/extension_log_in_notification.png)
      </Step>
      <Step title="Select you token" icon="mouse-pointer-click">
        ![App Select Token Screen Pn](/flow/devs/images/app_select_token_screen.png)
      </Step>
      <Step title="Click on Confirm" icon="square-mouse-pointer">
        
      </Step>
    </Steps>
  </Step>
  <Step title="You're now authenticated" icon="party-popper">
    The extension initializes its configured services after authentication. Scan and guardrail behavior depends on the enabled features and project configuration.
  </Step>
</Steps>
