## Pull request detection

Symbiotic automatically scans supported pull requests after they are opened and
after new commits are pushed. Draft pull requests are skipped until they are
ready for review. The scan compares the pull request with its target branch and
reports vulnerabilities introduced or remediated by the change.

Scans run for both code and infrastructure files when applicable. A pull
request scan is also refreshed when the pull request is reopened or marked
ready for review.

### Security summary

When the scans complete, Symbiotic creates or updates a **Symbiotic Security
scan results** comment on the pull request. The comment lists vulnerabilities
introduced and remediated by the pull request.

![Security Summary](/flow/admins/images/security_summary.png)

For each introduced vulnerability, the summary includes:

- A display ID and severity
- The rule ID and vulnerability title
- The file path
- The affected line or line range

<Info>
  Select the rule ID to open the vulnerability database. Select the file and line to open the relevant location in the pull request diff.
</Info>

![Summary Table](/flow/admins/images/summary_table.png)

The summary can also include remediated vulnerabilities. If there are more
findings than the comment displays, use the IDE extension to view the complete
results.

### Review a vulnerability

To review an introduced vulnerability, post `/symbot review <vuln-id>` as a
comment in the main pull request conversation. Replace `<vuln-id>` with the
display ID from the security summary. Symbiotic posts an inline review comment
on the affected code with:

- The rule and vulnerability explanation
- The potential impact
- A remediation suggestion or diff, when available

![Review Comment](/flow/admins/images/review_comment.png)

### Chat and suppression

To ask a follow-up question, reply to a Symbiotic review comment with
`/symbot` followed by your question. You can also reply with one of these
commands:

- `/symbot ignore` to request a suppression comment
- `/symbot false positive` to report that the finding is a false positive

![Chat Comment](/flow/admins/images/chat_comment.png)

<Info>
  `/symbot review <vuln-id>` is supported in the main pull request conversation. Follow-up, ignore, and false-positive commands must be posted as replies to a Symbiotic review comment.
</Info>

## Pull request activation

The VCS integration can show a warning comment on monitored repositories to
encourage developers to scan their branch with the Symbiotic IDE extension
before opening a pull request. Administrators can enable or disable warning
comments for each repository in the repository settings. New repositories use
the organization's default setting.
